# 트레이더 영상 학습 — 새 세션용 인수 문서

목표: 불장단타왕, 돈깡(강민우), 침착해, 만쥬, 수급단타왕의 **구체적 매매 규칙**을 영상에서 찾아낸다.
이들은 규칙을 직접 말하지 않으므로, **서로 다른 영상·채널에서 같은 주제를 반복해서 말한 것만** 합의로 모은다.

## 역할 분담
- **이 새 세션(수집 담당)**: TubeAlfred 커넥터로 자막을 받아 합의를 추출하고, **요약(자기 말로 정리)** 만 저장소에 커밋한다.
- 기존 세션(검증 담당): 요약을 받아 코인 데이터로 백테스트한다(시세 데이터는 기존 세션 컨테이너에 있음).

## 먼저 할 일
1. 브랜치 `claude/vibrant-dirac-nuik1w` 를 체크아웃한다. CLAUDE.md·AGENTS.md 규칙(한국어 보고, 개인·원장 데이터 커밋 금지)을 따른다.
2. TubeAlfred 커넥터가 이 세션에 로드됐는지 확인한다. "연결" 버튼이 비활성이면 사용자에게 이 세션에서 연결하도록 요청한다.
3. `pip install youtube-transcript-api yt-dlp` 는 필요 없다(유튜브가 클라우드 IP를 차단). 자막은 커넥터 도구로만 받는다. 차단 우회(쿠키, 위장 등)는 하지 않는다.

## 절차
1. `tools/research/seed/priority_videos.json` (42개) 의 영상 자막을 TubeAlfred 로 받는다. 한국어 자막 우선.
2. 받은 자막을 `research_data/youtube/inbox/<영상ID>.txt` 로 저장한다. (`research_data/` 는 .gitignore — **절대 커밋하지 않는다**.)
   메타(채널, 제목)는 `YT_DATA_DIR` 의 `index.json` 에 넣거나, 아래 명령 전에 `python3 tools/research/yt_ingest.py search "<제목>"` 으로 채운다.
3. `python3 tools/research/yt_ingest.py inbox` → `digest` → `consensus --top 8` 실행.
4. 아래 주제별로 **같은 내용이 ≥2개 영상 & ≥2개 채널**에서 나온 것만 표로 정리한다.
   손절 기준, 손익비 하한, 분할매수 방식, 분할매도 방식, 종가베팅 진입 조건(시각·거래대금·수급·차트 형태), 수급 판단 기준(연속 일수, 외국인·기관), 장세 구분(하락장·횡보장 대응), 종목 선정, 하루 손실 한도, 하지 말아야 할 것.
   각 항목마다: 내용 / 근거 영상ID@mm:ss (최소 2개) / 인물별 일치·불일치 / 확신도(합의·단독 주장).
5. 우선 목록에서 빠진 주제가 있으면 `candidate_videos.json`(155개) 에서 추가 영상을 받는다.
6. 결과를 `docs/artitrade/research/YT_CONSENSUS_<날짜>.md` 로 작성한다.
   - 자기 말로 요약. 원문 문장은 짧게(한 줄 이내)만, 자막 전체·긴 인용 금지(저작권).
   - 합의가 안 된 것은 "단독 주장"으로 따로 표기하고, 추측으로 채우지 않는다.
7. 커밋·푸시는 개발 브랜치에만(트러스트 브랜치 금지). 완료 후 기존 세션에 알린다.

## 보고 형식
한국어. "문제였던 것과 그에 따른 효과 / 수정 후 개선된 내용 / 확인하지 못한 것 / 결정 요청" 순서. 자막 품질(자동 생성 여부)과 영상 수를 반드시 적는다.
