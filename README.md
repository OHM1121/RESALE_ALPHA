# RESALE ALPHA V0.3

Galaxy S25 Ultra용 중고거래 ALPHA 분석 + 수요확정 앱.

## 핵심 기능
- 당근 / 중고나라 / 번개장터 공식 검색 바로가기
- 공유받기 -> 매물 후보/수요글 등록
- 3마켓 비교가 중앙값, 예상순차익, ALPHA SCORE, 안전 최대매입가
- MY VAULT
- DEMAND LOCK
  - 원매물 유효상태 관리
  - 확실수요 2건 이상 확인
  - 구매자 1명 확정
  - 직거래/택배 분기
  - 사용자 진행 승인 필수
  - 택배 선입금 수동 확인
  - 매입완료/배송정보 요약/거래완료
  - 환불 준비
- 주소/전화/입금자명/환불계좌는 Android Keystore AES-GCM 암호화 저장

## 중요
세 플랫폼의 비공개 API 우회, 로그인 자동화, 자동 대량 크롤링은 하지 않습니다.
실제 계좌 송금/환불은 금융 API가 연결되기 전까지 실행하지 않습니다.
