## 2. 소유자가 확정한 것 (정책·결정)
- 마켓트렌드 손절 = 직전 N봉(30m 200/60m·일 90) **최저가**, 종가 이탈 시 전량 매도(0.1.9, 2번안). MA 손절 = 직전 50봉 최저가. 하드손절 -15%.
- 시장점수 ≤ -10이면 MA·마켓트렌드(주식·코인)의 **종목당 한도**를 절반(바닥), 점수가 오르면 복구. 매수 자체를 막지 않음(2026-11-20 규칙 유지). AT·GMO·CW 불변.
- 보유카드: "1차 수익목표" 표기, 손절가가 여럿이면 가장 가까운 것 + 괄호 안 예상 손실률(숫자%).
- 각주 삭제 방침(키움 공식 REST·고유 거래 ID 등), 서랍(접기) 항목은 소유자가 닫을 때까지 열려 있어야 함.
- 선차트: 0 이상 초록, 음수 빨강(한 선에서 색 변경). 통합 대시보드: 주식/코인 구역 접기, 접어도 확정/보유 막대 표시. 목표확인 비중·매매 흐름 삭제.
- 0.1.3~0.1.5 원장 초기화 3단계는 소유자 명시 지시(수급매매 GMO 제외).

## 3. 작업 절차 (이번 세션에서 확정된 방법)
1. 수정 → 로컬 테스트 → **GitHub Issue 새로 생성(항목마다 고유 번호)** → `version_issues.json`(entries + `candidate_0XX`)·`dependency_graph.json`·`DEPENDENCY_MAP.md` 갱신 → `validate_governance.py` → 개발 브랜치 커밋·푸시.
2. 서명 워크플로: 직전 `.github/workflows/artitrade-0NN0-trusted-branch-signer.yml`을 복사해 `VERSION`, `VERSION_CODE`, **`PREVIOUS_VERSION`, `PREVIOUS_VERSION_CODE`**(빠뜨리면 R1 단계에서 즉시 실패), `SOURCE`/`ref`(직전 소스 커밋으로 고정), 릴리스 노트, 회귀 테스트 목록(새 테스트 추가)을 교체. 개발 브랜치에 커밋 후, 임시 worktree(`/tmp/tb`)에서 신뢰 브랜치에 **그 파일 1개만** 커밋·푸시하면 빌드 시작. 소스를 다시 커밋하면 `SOURCE`를 새 커밋으로 다시 고정해야 함.
3. 완료 후 `gh api repos/.../releases/tags/<ver>`로 자산 id를 얻어 `gh api -H "Accept: application/octet-stream" .../releases/assets/<id>`로 받음(**`gh release download`는 GraphQL이라 이 환경에서 403**). SHA256 대조 후 채팅으로 APK 전달(`SendUserFile`), 문서에 CI_VERIFIED 기록.
4. 클라우드 세션은 소유자 PC에 접근 못 함(`list_computer_folders` 빈 목록). 보고 시 매번 "PC에서 `tools/artitrade/fetch_latest_apk.ps1` 실행"을 안내(R11).
5. **로컬 Java 컴파일 검증**(Android SDK 없이): Maven Central의 `org.robolectric:android-all:15-robolectric-14663667`(약 190MB)을 받아 클래스패스로 쓰고, `com.chaquo.python.{Python,PyObject,android.AndroidPlatform}`와 `com.artitrade.mobile.BuildConfig` 스텁을 만들어 `javac -source 17 -proc:none`으로 `app/src/main/java` 전체를 컴파일. 화면 렌더링은 확인 불가.
6. 로컬 Python 테스트: `PYTHONPATH=ARTITRADE_ANDROID/app/src/main/python:ARTITRADE_ANDROID/ui_tests`. 벤더 엔진(`d_engine`, `d_upbit`, `projectgmo` 등)이 필요한 테스트 18개는 로컬에서 항상 실패(CI는 엔진을 복원해 통과). 새로 깨진 것만 보면 됨. 엔진은 `app/src/main/assets/strategy_v070/part_*.txt`(base64 zip, SHA 고정, **수정 금지**; 오버레이 모듈로만 패치).
7. 로컬 테스트가 만드는 `__pycache__`는 `.gitignore`에 추가됨(커밋 금지).
