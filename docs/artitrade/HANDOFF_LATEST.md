## 3. 초기화의 정확한 범위 (구현 모듈: `ledger_reset_v0130.py`, `history_reset_v0140.py`, `candidate_reset_v0150.py`, 훅 `LedgerAntiRollbackV002.verify`)

## 4. 미해결·미검증 (정직하게)
1. **폰 실기 미검증 전부**: 초기화 후 수급매매 보유 유지, 나머지 지갑 0 복원, 새 매수대기·매수 생성, 새 손절·최초종가 진입 동작.
2. 매수 0건 문제 #113(주식 기준봉 PENDING without BUY)은 기기 자료 없이는 원인 미확정(열림). MA 후보 약 90%가 신선한 시세 없음 문제(#116/#118)는 0.0.20/0.1.0 수정, 장중 확인 전.
3. 새 정책 해석 가정(INFERRED): 손절 창은 "매수 시점 직전 완성봉 N개(최신봉 포함)", 이력이 20개 미만이면 손절 없음(HISTORY_SHORT), 마켓트렌드 첫 종가가 기울기 조건에 실패하면 그 사이클 소멸 등. 소유자 정정 가능.
4. 마켓트렌드 주식 30분봉 손절 창(200봉)이 폰 KRX 저장소 깊이보다 깊을 수 있음 → 부분 창 사용·기록.
5. 시장점수 `<= -10` 경계(기준봉)는 기존 테스트가 고정한 의도적 동작. 시트 문구 "-10보다 작아지면"과 경계 해석 차이 가능성(낮음).
6. 낡은 테스트들(정책 이전 기대값, 원본 엔진 한계)로 CI 목록 밖 약 50개 파일이 로컬에서 실패. 0.1.1 이전 기준선과 동일함을 확인(내 변경이 새로 깨뜨린 것 없음). 정리는 미착수.
7. PC용 `verify_phone_backup`은 분할 백업(0.1.1) 형식을 읽지 못함. 분할 백업은 `analysis/restore_parts.py`로 복원.

## 5. APK 전달 (규칙 R11)와 현재 막힌 점
- 클라우드 세션은 소유자 PC에 접근하지 못함(`list_computer_folders` 빈 목록). 그래서 `artitrade apk` 폴더 저장과 "휴대폰과 연결" 전송은 **클라우드 세션에서 불가**.
- 현재 가능한 방법: PC에서 `tools/artitrade/fetch_latest_apk.ps1`(릴리스 APK 다운로드 + SHA256 검증 + 폴더 열기). 소유자가 실행해 폴더가 열리는 것까지 확인됨. 이후 전송은 소유자가 "휴대폰과 연결"로 직접.
- 소유자 요구: **APK를 내가 자동으로 폴더에 넣고 폰으로 전송**. 가능한 경로는 (a) PC의 Claude 데스크톱 앱 **로컬 세션**에서 작업(폴더에 직접 저장 가능, Phone Link는 화면 조작 권한 승인 시 시도 가능), (b) Tailscale 파일 전송(Taildrop) 스크립트화(소유자가 중단 지시한 상태, 미커밋). Phone Link 자체는 명령줄이 없어 자동화 불가.
- 폰에 도착했다고 주장하지 말 것(폰 확인 전).
