## 2. 원본 매매 전략 및 절대 보호 규칙

- 총 8개 독립 원장: 주식 AT(기준봉), MA, GMO(수급), CW(종가), MarketTrend / 코인 기준봉(Reference), MA, MarketTrend.
- NEW LEGACY(11.18) 변경 적용 대상은 주식 AT·MA·MarketTrend와 코인 기준봉·MA·MarketTrend의 6개 전략이다. GMO·CW는 기존 매수·매도·원장·손익·이력을 반드시 유지한다.
- 주식 AT 및 코인 기준봉은 실제 매수 시 해당 시장의 서명된 점수가 반드시 0 초과여야 한다. 0, 음수, 누락, 오래된 점수에서는 매수 금지. 후보 선정 시 점수와 실제 매수 시 점수를 구분한다.
- 기준봉 전략 목표가는 원본 분봉에 따라 1차 +2%/+3%/+3.5%/+4%, 2차 추가 +2%/+2%/+2.5%/+3%이다. 최초 매수수량 기준 1차 30%, 2차 35%를 예약한다. 추가 손절·만기·후행조건은 원본 정책 및 NEW LEGACY(11.18).xlsx와 대조한다.
- MA는 MA120 기울기 상승 전환, MA5·10·20·60이 MA120 아래면서 기울기 상승인 조건. 5분 48시간, 30분 80시간, 60분 120시간, 일봉 15일과 -15% 손절을 유지한다.
- MarketTrend 신규 매수는 30분·60분·일봉만 허용. RSI20 30 이하의 24시간 감시, 볼린저밴드 20/1.5 중심선 기울기 (-20,+30) 엄격 적용, 실제 중심선 접촉, 거래대금 TOP50 및 -15% 손절을 유지한다. MarketTrend 5분봉 신규 매수는 금지하되 기존 보유 포지션의 매도 복구는 유지한다.
- PAPER 가상계좌의 30%/35% 목표 매도 예약은 프로그램 내부 PAPER_RESTING 계획이지 거래소에 전송된 실지정가 주문이 아니다. 실제계좌 사전 지정가 주문은 별도 승인·브로커 체결증빙이 있어야 한다.
- 원본 SQLite 매수·매도 체결, 현금, 수량, 수수료와 원본 포지션 ID가 유일한 거래 사실의 기준이다. UI·REST 현재가·과거봉 고가·캐시된 호가를 근거로 허위 체결을 만들거나 실제 주문을 수행하지 않는다.
- 원본 시세 수신기, 공식 확정봉, 호가 신선도, FreshEpochGate, LedgerAntiRollback, 8개 전략 지갑을 우회하거나 일괄 초기화하지 않는다.

## 4. 남은 우선 검증 과제

1. 실기기에서 0.0.16 사전로딩 화면이 매번 나타나는지 확인. 진행률이 실제 체크 항목과 연결되고, 예상시간은 측정된 수신속도에 따라 표시되는지 검증. 화면 종료 뒤에도 원본 확정봉 복구·보유 매도 감시가 지속되는지 확인.
2. KRX 0B/0D와 Upbit 체결·호가의 장중 수신, 오래된 데이터 차단, 누락 최신 공식봉 복구 확인. 이슈 #93의 원본 SQLite HISTORY_INDICATORS 잠금 지연(기존 로그에서 약 6.2초)과 주식 PENDING→BUY 병목도 실기기로 추적. 유효 호가가 없으면 허위 체결 금지.
3. MarketTrend 실제 원본 BUY 체결이 있는 주식·코인 포지션별 매수가, 부분매도, 실현손익·수익률을 원본 SQLite/보유종목/체결이력/요약에서 대조. '마지막 저장 평가가'를 실시간 현재가나 체결호가로 오인하지 않도록 확인.
4. 기존 8개 지갑의 OPEN/CLOSED UID 안정성, 앱 재시작·동일종목 여러 회차·미연결 체결, 현금/손익 보존 검증. 원본 PK를 바꿔 연결 오류를 감추지 말 것.
5. CFG는 코인 MA 5분봉에서 이전에 신고된 '정확히 1개' PAPER 포지션만 원본 ID 등으로 특정한 경우에 한하여 정리. 원본 휴대전화 진단에 DELETE_ONE / SKIPPED와 재실행 결과를 남기고 확인. 모든 KRW-CFG 거래를 삭제하거나 삭제됐다고 추정하지 말 것.
6. 장중 원본 후보→PENDING→시장점수·확정봉·호가 검사→원본 매수/매도체결→원장→UI 단계의 첫 차단 사유를 오류이력에 기록하고, 주식 AT/MA, 코인 MA/Trend 및 기존 GMO·CW 포함 8개 전략 회귀검증 수행.
7. 공개 GitHub에는 개인정보, 인증정보, 사용자 거래원본 SQLite·ZIP, 실제 개별 거래 상세를 업로드하지 말 것. 실기기 증거는 비공개로 분석하고 공개 이슈에는 비식별 진단 요약만 기록한다.
