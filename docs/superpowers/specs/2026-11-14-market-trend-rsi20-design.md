# ARTITRADE v0.7.42 기반 마켓트렌드(RSI20) 전환모드 설계서
상태: 설계 초안 — 사용자 최종 승인 전 / 작성: 2026-11-14

## 1. 목적과 범위
주식·코인 기준봉/MA가 해당 시장점수에 따라 자동으로 매수방식을 전환하는 기능임. 마켓트렌드는 독립 전략·별도 화면·별도 시드가 아니며, 원래 전략에 속한 진입 모드임. 기존 매수분의 매도전략은 전환해도 바꾸지 않음. GMO/종가베팅과 기존 전략 원형의 매도조건·계좌를 임의 변경하지 않음.

## 2. 선택한 구조 및 대안
- 선택 B: 시장별 공통 RSI20 데이터/후보 감시 모듈, 매매모드 게이트, 종목 중복차단을 두고 기준봉/MA의 주문 실행과 원장·자금은 각각 독립 운영.
- 검토 A: 기준봉/MA마다 RSI 계산과 감시를 중복 작성. 기존 코드 수정범위·중복 API 호출·서로 다른 RSI 결과 위험이 커서 채택하지 않음.
- 기존 관측 구조: market_research_v033.py는 주문과 독립된 시장점수 연구엔진, android_operation_bridge.py는 시장×기준봉/MA×시간봉별 계좌·한도, ai_research_v040.py 및 ai_trade_lifecycle_v042.py는 연구전용 SQLite, UnifiedVisualActivity.java는 원래 탭 UI, StrategyRuntimeBridge.java는 내장 Python 코어를 연결함.
- 공통 RSI 모듈은 시장점수 산식이나 기존 RSI(14) 분석필드를 덮어쓰지 않음. RSI(20)는 별도 네임스페이스에 저장함.

## 3. 논리적 데이터 흐름
(1) 시장점수 읽기(주식/코인 각각) → (2) 0점 이상: 기존 기준봉/MA 신규매수, 0점 미만: 마켓트렌드 RSI20 신규매수 → (3) 공통 후보목록·실시간 RSI20 → (4) 종목 단위 원자적 중복매수 예약 → (5) 각 전략/시간봉의 기존 자금·최대보유 한도 검사 → (6) 해당 전략의 기존 주문 어댑터로 매수 → (7) 체결된 모드의 매도관리 유지 → (8) 실제/미매수 가상 관측을 별도 원장과 AI에 전송.

## 4. 시장점수 게이트·미체결 처리
- 점수 0 미만: 해당 시장의 기준봉 및 MA의 종전 신규매수 중단, 마켓트렌드 활성화. 0 이상: 기존 신규매수 재개, 마켓트렌드 신규매수 중단.
- 점수 전환이 정상 확인되면 비활성화된 매수모드의 미체결 잔량 취소; 이미 체결된 부분은 기존 모드대로 매도관리.
- 점수 조회 실패/오래된 점수: 해당 시장 신규매수만 중단; 실패 직전에 접수된 미체결 매수주문은 사용자 결정에 따라 유지. 조회 복구 후 비활성화 모드가 되면 취소.
- 주식/코인 점수는 독립 관리. 조회 실패 중에도 기존 포지션 매도·강제손절 감시 지속.
- 점수 유효성(조회시각, 품질/상태) 검증 없이 마지막 수치를 무기한 재사용하지 않음.

## 5. 종목 선정·RSI20
- 종목 후보: 코스피 당일 거래대금 상위 50, 코스닥 상위 50, 코인 원화마켓 거래대금 상위 40. 목록 5분마다 갱신.
- 5분봉, 30분봉, 60분봉, 일봉을 독립 계산. 공통 RSI 계산은 Wilder RSI(20), 직전 완성봉과 진행 중 실시간 종가를 분리. 적절한 과거 봉·타임스탬프·실시간 시세가 없거나 지연되면 매수 차단 및 근거 기록.
- 실매매용 진행봉 RSI는 키움/업비트 실시간 데이터 경로에서 계산하고, AI 연구전용 공개 OHLCV 수집기의 저빈도 조회결과만으로 봉 마감 12초 전 주문을 내지 않음. 연구 데이터는 주로 보강/사후검증용임.
- RSI 40 이하 관심종목 집중 감시. 새로 편입된 종목이 이미 RSI 30 이하라면 즉시 매수하지 않고, 해당 시간봉의 마감 확정 RSI가 30 초과한 뒤 새 과매도 구간 진입을 기다림.
- 한 시간봉의 재진입은 마감 확정 RSI가 30 초과하여 무장(re-arm)한 뒤, 다시 봉 마감 직전 실시간 RSI 30 이하 신호가 있어야 가능함. 중간에 실제 매수 실패한 경우에도 같은 과매도 구간 재주문 금지.
- 일반 시간봉 매수: 마감 15초 전 실시간 RSI <=30 확인, 마감 12초 전 주문 제출. 실제 가격·시각·체결 여부는 브로커 응답으로 확정; 정확한 체결시각은 보장하지 않음.
- 주식 15:20~15:30 신규매수 금지. 15:30 마감 일봉·60분봉·30분봉은 예외적으로 15:19:45 판정, 15:19:48 주문, 15:20 미체결 잔량 취소. 시간봉이 15:30 마감하는지 실제 세션/봉 경계로 확인.
- 코인 일봉 시각은 연결 거래소의 공식 캔들 경계 기준.
- 여러 시간봉이 같은 시점에 유효 신호라면 일봉 > 60분봉 > 30분봉 > 5분봉 순서.

## 6. 자금·경합·보유 차단
- 각 시장의 기준봉과 MA는 각각 기존 전략 시드/사용가능 현금/최대보유 수를 유지. 모드용 전용자금 없음. 기존 시간봉별 계좌를 그대로 선택하여 주문.
- 동일 시장·동일 종목은 시간봉, 기준봉/MA를 가로질러 한 실보유/활성매수주문만 허용. 실거래용 종목 예약은 원자적이며 주문 취소/거절/체결 확인 뒤만 해제.
- 두 전략이 경쟁하면 먼저 신호 확정한 쪽 우선. 정확히 동시라면 기준봉·MA 순환 배정하고 이력 유지.
- 기존 보유종목의 매도 로직과 대기 주문 관리까지 포함해 현재 보유·예약 여부 검사. 매수금액 및 중복제한은 원장과 브로커 상태로 재검증.
- 가상매매는 실제 운용자금·보유제한·신규매수 판단을 변경하지 않음.

## 7. 매수봉 확정 및 매도가
- 매수봉 마감 전 일반 수익실현/매수가 복귀/RSI +3봉 매도는 비활성. 단, -9% 강제손절은 매수봉 마감 전부터 즉시 적용.
- 매수봉 마감 후 최종 고가 H/저가 L로 목표값을 고정. 기준폭 r=(H-L)/H (H>0), 목표 가산율 d=min(r, 0.03).
- 1차: 원칙적으로 매수봉 고가 H에 도달하면 최초 매수량의 30% 매도. 실제 매수가가 H와 같거나 위라면 1차 목표는 실매수가×(1+d). 고저폭 3% 상한 적용.
- 2차: 1차 목표가×(1+d)에 도달하면 최초 매수량의 35%(남은 70%의 절반) 매도. 1차 체결 후 1차 목표가 이하로 되돌리면 잔량 청산.
- 3차: 2차 매도 체결 후 남은 약 35%는 2차 체결 이후 관측 최고가 대비 4% 하락 또는 2차 목표가격 이하 회귀 중 먼저 충족한 조건으로 전량 청산. 2차 체결 시점 이후 최고가 갱신 추적.
- 1차 전에는 매수가를 넘어서 상승한 뒤 매수가 이하로 재하락하면 전량 청산. 이는 조건 발동가이며 그 가격 체결을 보장하지 않음. 1차/2차 이후에는 각 단계의 높은 보호가격이 우선.
- 예시: 매수 10,000, H 10,000, L 9,600 → r=4%, d=3%; 1차 10,300원, 2차 10,609원. 호가단위로 보정한 주문가격 별도 기록.
- 매도조건 동시 충돌 시 강제손절, RSI 강제청산/보유기간 만료, 이미 활성화된 단계별 보호·수익실현 중 유효한 주문을 단일화하여 중복 전량매도 방지. 주문 체결량 확인 후 잔량만 재주문.

## 8. RSI 강제청산 및 재진입
- 최초 확정된 과매도 구간을 0봉으로 정의. +1/+2봉은 마감 확정 RSI20 <=30 연속 확인; +3봉은 마감 직전 실시간 RSI20 <=30이면 잔량 100% 매도.
- 연속 구간 중 마감 확정 RSI20 >30이면 횟수 초기화. 선제매수 봉의 최종 RSI >30이어도 포지션은 유지하되 연속 과매도 횟수 초기화; 이후 새 연속 과매도 구간에서 다시 계수.
- 봉 마감 전 확인 RSI<=30이었지만 마감 확정 RSI>30이어도 체결된 매수는 취소/강제청산하지 않음.
- -9% 강제손절: 실평균 매수가 대비 시세 <=91%에서 잔량 100% 매도주문 즉시 제출. 매도 발동기준이며 체결가·실현손실은 유동성 등에 따라 달라질 수 있음.
- 마켓트렌드 -9% 손절 종목은 해당 날짜(KST) 마켓트렌드 재매수 금지. 주식은 다음 거래일, 코인은 다음 날짜부터 해제. 시장점수 0 이상 복귀 후 원래 기준봉/MA 매수까지 금지하지 않음.

## 9. 최대 보유기간
- 5분봉 48시간, 30분봉 72시간, 60분봉 120시간, 일봉 10일.
- 코인: 실제 체결시각부터 연속 실시간 48/72/120시간, 일봉은 10×24시간.
- 주식: 휴장일(주말, 공휴일) 날짜는 시계에서 제외, 정규 거래일은 장외 시간 포함 24시간 단위로 적산. 일봉은 10거래일(24시간×10 유효일)로 해석. 예: 금요일 10시 5분봉 체결 → 화요일 10시 만료(중간 공휴일 없을 때).
- 만료 시점이 거래 불가능하면 다음 정규장 거래 가능 시각에 매도 제출. 거래소 캘린더 불명확하면 임의로 거래일을 지어내지 않음.

## 10. 보존·AI 분석 연동
- 기존 연구이력 및 시장별 AI SQLite를 유지하며 마켓트렌드 전용 이벤트/피처를 증분 추가(기존 기록 불변). 원래 전략 ID(stock.at, stock.ma, coin.general, coin.ma)를 보존하고 entry_mode=market_trend 속성으로 구분.
- 주요 필드: market, parent_strategy, frame, symbol, signal_id, time/bar_id, score/score_ts, rsi20_live, rsi20_closed, H/L, proposed/actual price, broker_order_id, filled_qty, signal_disposition, block_reason, exit_stage/reason, exit_rsi20, realized_pnl, fee/tax, source/freshness, observed_at.
- RSI 40 이하 관심종목은 타임스탬프와 RSI 경로, 이후 가격 경로를 저장. 거래 판단용 원시 시세처리와 연구 저장주기를 분리하고, RSI 구간진입/해제·매수신호·봉마감·청산 등 핵심 이벤트는 빠짐없이 기록하되 고빈도 틱 데이터로 저장공간이 무제한 증가하지 않도록 관리. 미매수 조건충족 신호는 별도 paper-only 가상진입·가상매도와 가정 가격·불확실성을 기록, 실제 거래 손익에 합산 금지.
- 기존 AI의 RSI14 필드와 새 RSI20을 혼동하지 않음. AI 분석탭에서 진입 RSI 구간·시간봉·시장점수·확정 RSI 편차에 따른 실제/가상 성과를 분리하여 분석. 분석은 원칙적으로 사후 연구이며 자동으로 매수 기준을 바꾸지 않음.
- 앱 재시작, 백업/복원, 연구 ZIP 추출 이후에도 추적 상태·보유모드·중복차단·연속 RSI 상태·가상매매 일관성 복구.

## 11. 사용자 화면
- 마켓트렌드 별도 탭 없음.
- 기존 기준봉 탭: 현재 적용 매매법: 기준봉 / 마켓트렌드
- 기존 MA 탭: 현재 적용 매매법: MA / 마켓트렌드
- 점수 조회 불가 시: 신규매수 중단 사유를 현재 탭의 상태메시지로 표시. 전략/자금/연구탭 전체 구조는 유지.
- 현재 화면의 매수/매도 원장에는 기존 기준봉/MA 소속으로 집계하되, 개별 거래의 진입 모드와 RSI20 확인 가능. 성과 중복 합산 금지.

## 13. 설계상 세부 기본값(최종 승인 시 함께 승인되는 제안)
- 2차·3차 보호값은 단계별 체결이 확인된 후 활성화. 진입봉 고저폭이 0%이면 이익목표가 매수가와 같아지는 문제가 있으므로 별도의 한 틱 상향 또는 진입 취소 방침을 구현 시 검증하고 문서화(사용자 승인 없이 임의 매매규칙 추가 금지).
- 시장점수와 시세의 신선도 허용치는 기존 실제 업데이트 주기/거래소 통신 사양을 확인해 설정. 오래된 데이터로 매수하지 않음.
- 종목간 공유 중복매수 예약은 가상매매에 적용하지 않음. 중단·강제종료에도 거래 상태가 유실되지 않게 SQLite에 체크포인트를 기록함.
- 15:20 미체결 취소 규칙은 시장점수 오류 시 미체결 유지보다 우선함. 점수 조회 실패 중 유지한 주문도 15:20이 되면 주식에서는 취소.
- 기존 전략 포지션/마켓트렌드 포지션은 소속과 진입모드를 별도 기록하고, 진입 당시 결정된 매도정책이 종료 전까지 바뀌지 않음.
