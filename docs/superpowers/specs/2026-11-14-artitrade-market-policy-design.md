# ARTITRADE v033 — 정책 종목 필터 / 시장 브리핑과 구간별 보유수익률 연구
작성일 2026-11-14. 기존 통합 APK v0.7.32, 주식·코인 EXE 원본을 기준으로 설계함.

## 확인한 원본
- 사용자 업로드 주식 EXE의 `app/d_market_briefing.py`: 11개 원가중 지표의 방향성 점수 -100~100, _evidence의 가중 평균, _analog 과거 유사국면, _feedback 예측 사후판정; refresh 180초.
- 원본 주식 EXE에는 점수대별 보유종목의 퍼센트포인트 변화를 누적하는 동일 기능은 확인되지 않음. 이 기능은 새 원장에 구현.
- 코인 시장 분위기 0~100 점수는 새로운 연구지표. CoinGecko/alternative.me 및 공개 Upbit API를 참고하되 당사 자체 구성 점수임. 위험도 평가가 아니라 관측요약임.

## 사용자가 보는 내용
- 상단 시장 / 주식 / 코인, 맨 왼쪽 시장. 시장 화면은 주식 및 코인 실측 점수, 점수 근거 구성요소/시각/출처/커버리지, 구간별 보유종목 변동률 평균/표본을 그래픽 게이지와 표로 표시. 점수 미산출이면 미수신·자료부족 표기, 가짜 50점 금지.
- 시장 점수 구간: 0~50, 51~60, 61~70, 71~80, 81~90, 91~100. 점수 55일 때 51~60, 20일 때 0~50.
- 구간이 바뀌는 그때의 종목별 보유수익률(매수가 대비 %), 종목코드 및 전략/계좌, 원장 기준 현재가를 별도 원장에 저장. 55점 -4%에서 +2%가 되면 개선 +6%p. 구간 전환은 새 스냅샷으로 시작. 구간에 참여한 원래 보유종목만 추적; 이후 새로 매수한 종목을 과거 표본에 소급 추가 금지.
- 동일 종목의 서로 다른 전략/시간봉 계좌는 다른 참가자로 추적. 동일 계좌 안 중복 다회 매수는 가능한 경우 실제 포지션 ID로 구분.
- 시세 수신이 없거나 기준 매수가 없는 종목은 제외. 원장의 last_price는 시각이 없으면 시각 불확인으로 표시; 가상의 시세를 생성하지 않음.
- 종료된 매매는 실현 매도체결가 검증 시에만 마지막 변화 반영; 근거 없으면 마지막 검증된 관측에서 중단(신선도 표시).
- 점수구간 변화시 이전 구간 완료 후 새 구간 시작. 데이터 기록은 거래판정과 독립, 실매매 조건 미변경.
- 각 보유종목의 정책이력 버튼은 눌린 종목의 현재 시장+전략+코드에 해당하는 BUY/SELL 체결 이력만 보여줌. 설정창의 전체 정책이력은 기존 전체목록 기능 유지.
- 정책이력 표: 종목명 | 매수/매도 | 매수/매도 근거 | 체결 시점 | 당시 시장점수. 현재 점수로 과거 이력을 채우지 않고, 체결시점 이하의 실측 score를 엄격한 신선도 내에서만 연결. 없으면 미기록.
- 주식 점수: 원본 EXE _evidence 가중치, 임계·방향, (raw+100)/2 변환. 키움 지표 미수신/해외시세 오류는 부분 지표 사용 및 커버리지 표시. 프로그램은 브리핑 연구용이며 주문에 개입하지 않음.
- 코인 점수: KRW 전체 종목 상승 비율/거래대금, BTC 7/30일 추세, ETH 상대강도, BTC 변동성; 가능한 데이터에만 가중치 적용. 최소 자료 미충족이면 점수 미기록.
- 시장 데이터는 수동 주문/자동 주문 실행 스레드를 막지 않도록 별도 동기화/수집 스레드로 운영하며, 네트워크 지연·차단은 기존 주문 정책을 건드리지 않음.
- GitHub 코드/테스트/서명된 통합 APK는 과거 apk와 같은 application ID + signing cert로 업그레이드. 원본 Windows EXE 주문엔진은 수정하지 않음. EXE가 변경된다면 원본 실행부·원장과 기능동등 검증 필수.

## 제약과 명확성
- 원본 주식 EXE의 미래 예측 상관관계는 수익률 추적의 성과보장이 아님.
- 입수되지 않은 과거 시점 데이터는 절대 소급 계산하지 않음.
- 업비트 API 호출 한도는 https://docs.upbit.com/kr/reference/rate-limits 및 day candles / ticker(all) 참조.
- 암호/키를 앱 외부에 보내지 않음; HTTPS 공개 market data만 사용.
