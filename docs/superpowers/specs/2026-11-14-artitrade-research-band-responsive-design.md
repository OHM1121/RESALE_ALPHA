# ARTITRADE v031 — 점수 구간 더블탭·화면 가로 배치 설계
- 요구: 주식 4전략 + 코인 2전략의 점수 × 시간봉 매트릭스 각 행을 더블탭하면 해당 점수 구간의 모든 로드된 후보를 모달 표로 보여줌. '닫기' 버튼 필수.
- 팝업 열: 종목·전략, 매수 조건 충족일(D일), 매수가격(매수일자), 매도가격 또는 목표 관측가(일자).
- 선정·불채택, 원장체결·가상 관측, 후속 최고가를 혼동하지 않음. 매수/매도 체결 값은 원본 체결가와 일자만 표시. 실제 체결가 미기록 시 목표가를 허위 매도가로 대신하지 않음. 수급매매는 PAPER 체결과 관측 고가를 구분.
- 출처: 기존 연구 원장 SQLite/JSON read-only. 시세가 전해지지 않은 구간의 '미기록' 허용. 새 신호/주문을 생성하거나 거래 규칙을 수정하지 않음.
- 스코프: 점수 구간은 0~20,21~40,41~60,61~80,81~100,점수없음. 시간봉은 5m/30m/60m/day, GMO/종가베팅은 단일. '전체 전략' 필터에서는 주식의 GMO·CLOSE까지 노출.
- UX: 터치 위젯은 정상 스크롤을 방해하지 않고 두 번 터치했을 때만 열림. 팝업은 가로 화면의 90%가량 사용, 고정 헤더·스크롤 내용·닫기. 대상 데이터는 현재 로드된 목록이며 UI 원본 일부만 로드된 경우 그 제약 명시.
- 화면 공간: 리서치 판단근거, 점수 후보, 오류 이력, 정책이력 및 운용설정처럼 좌측 세로 문단만 있던 곳은 각 내용의 역할에 맞춰 2~4열과 가중치로 배치. 보유·대기·체결의 기존 가로 지표 도형은 보존. 소형화면은 겹치지 않게 필요시 세로 전환.
- 범위 제한: v030 코드 전용 브랜치에서 새 브랜치; 기존 전략별·통합 연구 ZIP, PC 버튼, 시작화면, 스와이프 기준 유지. EXE·APK 생성 금지.
- 확인: 리서치 고가만으로 매도일자/체결가를 채우지 않음, 구간 경계 및 GMO 프레임, 모달 터치 매핑, Java UI 컴파일, 기존 Python 연구 테이블 테스트.
