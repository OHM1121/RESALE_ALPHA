# ARTITRADE 종가베팅 손익 표시 보정 · 2026-11-12

## 문제
- 주식 종가베팅(CLOSE)의 확정 매도 손익은 PC 원장에 `executions.net_realized`로 저장되지만, 통합 체결 이력은 `net_profit`을 표시하여 빈 칸이 발생했음.
- 주식 종가베팅 계좌의 실현손익은 전체 대시보드 집계에 포함되지 않았음.
- 보유중인 종가베팅 종목의 평가손익은 수수료·세금 차감 전 기준이었음.

## 수정
- Windows 주식 EXE: 매도 체결을 읽기 전용으로 정규화하면서 확정 net_realized를 UI net_profit에 연결. 계좌 실현손익, 미실현 평가손익, 일별·기간별 집계에 CLOSE 포함. 부분매도는 이미 확정 처리된 매수 수수료를 중복 차감하지 않음. 실제 주문/전략 로직과 DB 스키마는 건드리지 않음.
- Android 주식/코인 조회 UI: SELL 행은 저장된 net_profit 또는 net_realized 같은 실제 순손익 필드만 표시. 수익 필드가 없을 때 판매가격/체결가격을 순수익처럼 표시하지 않음. 매수(BUY)의 순수익 칸은 미확정(—)으로 유지. 보유 포지션은 서버가 제공한 순수익 값(net_pnl)을 우선 표시.
- 앱 버전: 주식/코인 v0.3.2-CLOSE-PNL. 폰 서버 앱 버전/DB는 변경하지 않음.

## 중요한 현황 및 제한
- PC의 실제 종가베팅 매매 장부를 확보할 수 없었으므로 실제 장부 값과 대조하지는 못했음. 테스트는 가상 SQLite 레코드를 사용했음.
- 모바일은 폰 서버 조회 전용 앱이며, 실제 자동매매 엔진을 이식한 버전이 아님.
- 폰을 원본 장부로 전환하려면 별도의 전체 DB 마이그레이션과 주문 상태 조정이 필요. 현재 PC 한 번 업로드 도구는 최대 최근 100건의 표시용 스냅샷만 이관하므로 이 파일로 PC 매매 장부를 복원해서는 안 됨.
- 폰 서버의 SQLite를 삭제하거나 폰 서버 앱을 제거하면 원본 서버 기록을 잃을 수 있음.
- 기존 20초 PC→폰 반복 업로드 도구는 더 이상 사용하지 않음.
- 증권사 실거래/API 주문 실행은 이 UI 업데이트에서 변경하지 않았음.
