# ARTITRADE 모바일 v0.4.0 — 전략별 화면·한국어·기록 내보내기

## 적용 범위
- 삼성 S21+ 가로 화면에서 주식은 기준봉 → MA → 종가베팅 → 수급매매, 코인은 기준봉 → MA 순서로 상단 전략 버튼 및 좌우 스와이프 전환.
- 각 전략 화면의 홈, 보유, 대기, 체결, 전략, 연구, 오류 탭은 별도 목록으로 필터링. 전략 변경 시 현재 탭을 유지하며 스크롤 최상단 이동.
- 체결/보유 정보의 주요 시각: 기준봉과 MA는 ref_ts, 종가베팅은 buy_at(entry_ts), 수급매매는 event_date 또는 매수일-1(달력 기준). 정보 부재 시 '미기록'.
- ISO+UTC/Z, +09:00, 콤팩트 숫자형 시간과 타임존 없는 KST 원장 문자열을 구분해서 Asia/Seoul 시간으로 표시.
- 코인은 SQLite에 저장된 한글 name 우선, 주요 코인 코드의 한글 대응표를 보조로 사용. 매핑되지 않은 종목은 임의의 이름을 만들어내지 않음.
- 체결 내역 선택 시 체결시각·수량·가격·매수/매도근거·실현순손익(매도만) 상세화면.
- 매매근거에 이미 한글이 있으면 그대로 짧게 표시. 영문 코드에 매칭되는 표준 사유는 한국어 단축표현, 알 수 없는 근거는 '근거 코드 확인 필요'로 표시하여 잘못된 매도근거를 만들지 않음.
- 연구 이력 및 오류 이력 별도 메뉴와 스마트폰 저장소 위치를 지정하는 JSON 내보내기. 공유된 PC 장부의 노출 가능 필드만 전달, 토큰/거래소 API 키는 내보내지 않음.
- 기존 폰 서버 API의 `stock/at`, `stock/cw`, `coin/general`, `coin/ma`를 계속 사용. 주식 MA/수급은 AT 원장의 tf 분리표시이며 서버가 별도 전략 장부를 제공한다는 의미는 아님.
- 폰 서버 앱과 DB는 수정하지 않음. 주식·코인 앱만 업데이트하면 됨.

## 누락을 감추지 않음
- 기존 PC→폰 최초 이관 도구 v1.2의 스냅샷에는 ref_ts, buy_at, reason 등이 누락될 수 있음.
- 해당 컬럼을 실데이터로 전달하는 PC 1회 메타데이터 재이관 v1.3 도구 별도 필요. 이미 폰에서 수정된 원장은 PC 쪽에서 덮어쓰지 않게 재이관 기본 동작 차단.
- 데이터가 없으면 빈 목록/미기록/— 표시. 연동되지 않은 전략에 임의 수익·체결·시각을 표시하지 않음.
- 현재 안드로이드 APK는 인증된 폰 서버 조회/내보내기 앱. 독립 매매 엔진, 시세구독, 주문, 권한 임대, PC 양방향 원장복원은 구현되어 있지 않음.
- 상용 실거래 배포/테스트를 통과한 APK가 아님. Galaxy S21+ 실기기 검증 필요.
