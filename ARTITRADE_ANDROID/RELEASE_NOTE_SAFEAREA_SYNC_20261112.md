# ARTITRADE v0.3.1 SAFEAREA-SYNC (2026-11-12)

## Android 주식·코인 APK
- Android 15+ 상태표시줄(시계/배터리/와이파이)·하단 내비게이션 바·디스플레이 컷아웃과 대시보드가 겹치지 않도록 Native WindowInsets 적용.
- Galaxy S21+ 가로 화면 및 Samsung DeX의 창 크기가 바뀌어도 OS 인셋 기준으로 여백을 재계산.
- 홈·보유·대기·체결·전략·연구·더보기에서 매 20초마다 폰 서버 원장을 다시 읽어 표시. 앱이 백그라운드 상태면 갱신 중단.
- 더보기 > PC / 폰 / 정지: 폰 서버의 선호 실행 기기를 선택. 실제 엔진이 서버 lease 를 확인하도록 연결되지 않은 상태이므로 주문을 발생시키는 기능이 아님.
- 화면에서는 활성 lease 가 없으면 PC/폰 '실행'이 아니라 '대기'라고 표시.
- 연결 토큰/API Key/Secret은 GitHub에 포함하지 않음.
- 주식·코인 기존 서버 토큰 페어링 기능을 유지. 폰 서버 APK/DB는 수정하지 않음.

## PC 자동 장부 동기화 별도 Windows 도구
- 사용자가 제공한 EXE 소스에서 확인한 Windows %LOCALAPPDATA% 장부를 읽기 전용 모드로 확인.
- 지정된 Tailscale 100.64/10 주소를 통해 기존 휴대폰 서버 `/v1/record` endpoint 로 revision 기반 스냅샷 전송.
- 로컬 원장에 쓰기 없음. 전송 중단 또는 충돌 시 원장을 변경하지 않고 다음 주기에 재조회.
- 장부 및 연구·설정 중 허용 목록 필드만 스냅샷: 액세스 키/시크릿/무제한 오류 문자열은 제외.
- Windows .exe 는 Go로 컴파일된 별도 동기화 보조도구임. 주식·코인 원본 EXE 내부 소스/주문 판단 코드는 수정하지 않음.
- 이 경로는 단방향 **PC→폰 조회용 스냅샷**임. 스마트폰의 거래 기록을 PC 장부에 역방향 병합하는 동기화가 아님.

## 미완료 및 주의
- 주식/코인 Windows EXE에 실제 주문 선행 lease 검증/임대 갱신을 연결하지 않음.
- Android에서 원본 Python AT/CW 및 코인 B/MA 실시간 전략을 실행·주문하는 APK는 아직 없음.
- Windows 바이너리 컴파일/모의 데이터 단위테스트와 Android GitHub CI 컴파일 완료는 실기기 정상 운용 검증을 대체하지 않음.
- 현재 원본 DB가 모의(paper) 장부일 경우 모바일에도 모의 데이터로 표시; 실거래 주문/잔고를 추정하거나 생성하지 않음.
- PC 동기화 보조 도구가 실행되어 있고 폰 서버/Tailscale가 살아 있어야만 새 스냅샷이 갱신됨.
- 기존 폰 서버 앱의 저장소를 삭제하면 기존 동기화 데이터가 손실될 수 있음.
