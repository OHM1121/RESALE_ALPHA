# ARTITRADE S21+ / DeX 숫자·도형 중심 모바일 UI

## 원칙
- 갤럭시 S21+의 가로 화면과 삼성 DeX에 맞추어 숫자·도형을 우선 배치.
- 큰 숫자(누적손익) > KPI(실현·평가·승률·보유/대기) > 실제 데이터의 수익곡선 > 보조 텍스트 순서.
- 긴 각주/설명 문장은 기본 화면에서 제거.
- 서버 연결, 실제 실행 기기, 조회 전용 여부 등 판단에 필수적인 상태는 짧은 텍스트를 유지.
- 데이터가 없는 손익/수익률/승률은 0이 아니라 —로 표시. 실제 성과 없는 그래프는 표시하지 않음.
- 아이콘 내비게이션은 홈 / 보유 / 대기 / 체결 / 전략 / 연구 / 더보기로 구분.
- 주식 AT/CW, 코인 B/MA를 분리하여 보여줌. 추후 수급매매/GMO, 종가베팅, 시간봉별 기능도 동일 시각언어로 확장하되 실제 엔진 기능을 삭제하지 않음.
- 정적 대시보드는 외부 CDNs/이미지/API를 로드하지 않고 오직 Android 앱 내부 자산에서 로드.

## 현재 APK 기능
- 폰 서버의 인증된 상태/원장 데이터에서 숫자/KPI/상세를 추출하여 출력.
- 설정/원장/연구 데이터 조회, 연결 토큰 등록, 서버 상태 확인, 오류기록 접근은 기존 Android 기능 유지.
- 원본 Windows EXE 매매 엔진은 아직 Android에 이식되지 않음. 주문 화면을 만들어 실거래가 되는 것처럼 보여주지 않음.
- 주식·코인 증권/거래소 API 키와 사용자의 개인 데이터는 이 공개 저장소에 포함하지 않음.

## 설치/검증
- Android GitHub Actions에서 컴파일된 APK는 디버그 서명 시험판.
- Actions 실행마다 서명이 달라 기존 주식/코인 APK의 업데이트 설치가 실패할 수 있음. 실패 시 **주식/코인 앱만** 제거한 뒤 새로 설치, 폰 서버에서 연결 토큰 다시 복사.
- **폰 서버 앱은 삭제하지 말 것**: 삭제하면 저장 원장/연결 토큰을 잃을 수 있음.
- APK 컴파일 성공과 삼성 S21+ 실기기·DeX 레이아웃 검증은 별개.
