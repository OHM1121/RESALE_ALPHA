# ARTITRADE v107 소스 작업 인수인계 · 2026-11-18

상태: PR #51 초안 브랜치 소스 수정 / APK 제작·배포 절대 금지 / 휴대전화 원장 초기화 미실행

## 1. 원장 초기화 전에 확정되어야 하는 코드
- **일회성 초기화 범위:** fresh_epoch_reset_v106.py 의 _history()는 stock/, coin/ 및 실행·시장점수·연구 관련 루트 DB/JSON/WAL 등을 대상으로 하며, 새 execution_entry_plans_v107.sqlite3 역시 초기화 대상이다.
- **LIVE/설정 제외:** 인증정보, 운영 설정, 실거래 증거 발견 시 초기화 차단, 외부 ZIP 보호는 유지한다. Android 동작 게이트 및 PC 과거원장 재승계 차단이 유지되어야 한다.
- **신규 원장 자료 정의:** 8전략의 실제 체결과 별개로 기록되는 매수후보 사유/타깃 근거 스키마를 **첫 초기화 전** 소스에 반영하였다. 이미 기록된 새 원장에 대해 별도 초기화나 교체를 수행해서는 안 된다.
- **중복 초기화 금지:** 최초 COMMITTED 이후 재실행은 ALREADY_COMMITTED이며, 신규 entry_plan DB를 삭제하지 않음. 임시 SQLite 회귀시험으로 확인.
- **원장 초기화 실행 연결 상태:** v106 초기화 준비 코드가 설치된 스마트폰 실제 실행 경로에 자동 연결되어 있지 않다. 원장 삭제는 실행하지 않았으며, 명시적 승인 없는 자동 초기화 금지.

## 2. 초기화 전후와 무관하게 적용 가능한 일반 로직
- 시장추세 RSI20: 해당 시간봉의 **최근 10개 확정 종가 RSI 중 최신 종가에서 최초로 30 미만**, 이전 9개는 모두 30 이상. 다음 봉 개시 시점부터 10초 미만인 동안만 기존 원본 마켓트렌드 지갑과 실제 새 호가로 PAPER 진입을 검토한다. 기존 진행봉 RSI35 빠른 BUY 워커 기동 중지.
- 점수: 최신 유효한 주식 시장점수 0 미만이면 주식 AT 신규 매수만, 코인 시장점수 0 미만이면 coin/base 일반 기준봉 신규 매수만 차단. 점수 0 이상은 기존 동작. 점수 미확인/만료 시 음수라고 지어내지 않는다. 나머지 전략, 기존 보유종목과 매도에는 영향 주지 않는다.
- 오류/연구 ZIP: 원본 SQLite/JSON/WAL을 보존하는 ZIP_DEFLATED 레벨1 압축과 실제 압축 크기 기반 파트 분할, SHA-256 색인/복원 유지. 연구이력/오류이력 모두 적용.
- 리서치 UI: 하단 연구 탭 숨김, 기존 연구 화면용 대량 사전계산/히스토리 복사 생략. AI 분석, 원본 연구 수집 및 ZIP 추출 유지.
- 매수근거: execution_entry_plans_v107.sqlite3 별도 WAL은 stock(AT/MA/CW/GMO/trend), coin(general/MA/trend) 후보의 원본 매수근거와 확인 가능한 후보 타깃을 **별도 후보 기록**으로 저장. 직접적인 체결/보유를 뜻하지 않으며, 아직 산출할 수 없는 정확한 SELL 타깃은 NULL로 남긴다. 원본 포지션 및 체결의 판단근거와 추출 시 대조해야 한다. 감사 기록 장애 시 원본 주문을 중단시키지 않는다.

## 3. 유지해야 하는 LEGACY 및 구 코드
- LegacyLedgerMigration.java: 구형 PC 원장 유입/마이그레이션 차단·마커 경로에 관여. 초기화 안정성 확정 전 삭제 금지.
- d_engine.PaperEngine 및 D19PaperEngine: 이전 보유/전환 기록 또는 현재 원본 D19 매수·매도 경로를 가질 수 있어 임의 삭제 금지.
- legacy_ma_exit_watch_v094.py: 과거 MA v061/v062 미청산 보유의 자동매도 보존 경로. 새 초기화 **완료 전에는 특히 삭제 금지**. 초기화 후에도 실기기 진입·이전 데이터 가능성 전체 검증 전 제거 금지.
- ma_epoch_v062/v067 및 각 후속 패치: 역사상 분리된 MA 지갑과 구 보유정책에 관여함. 파일명에 LEGACY가 들어간다는 이유만으로 삭제 금지.
- 코드 중 사용처 0%가 확인된 연구 탭 사전계산만 **실행 생략**. 이외 구 코드의 완전한 무영향은 입증되지 않아 물리 삭제하지 않았다.
