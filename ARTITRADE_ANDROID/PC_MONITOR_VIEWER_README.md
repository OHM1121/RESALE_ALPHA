# ARTITRADE PC · 자동 사전로딩 조회 전용 v1.1

PC EXE 실행 시 자동 진행:
1. 저장된 Windows DPAPI 페어링 토큰 확인.
2. 기존 MSERVER 주소로 즉시 연결, 접속 실패 시 Tailscale 안드로이드 기기 자동 탐색.
3. 새 주소의 MSERVER는 /health 서비스 식별 후 인증 토큰 전송.
4. 주식·코인 각각의 최신 원장 revision 조회 및 변경된 자료 다운로드.
5. 백그라운드 수신 중 진행상황 표시, 화면 표시 후 10초 간격 갱신.

최초 1회: Windows에 페어링 정보가 없다면 MSERVER 64자리 토큰 입력창이 열림.
수신 성공 후 토큰은 Windows DPAPI로 암호화 저장, 다음 실행부터 자동 연결.
토큰 입력 이후에도 '최신 원장 조회' 버튼을 누를 필요 없음.
Tailscale 기기가 여러 대라 자동 탐색이 애매한 경우 '연결 설정'에서 휴대폰 주소 지정.

조회만 수행하는 독립 EXE: 실제·가상 매매 및 거래소 API 주문 기능 없음.
기존 주식/코인 매매 EXE를 자동 종료시키지는 않으므로 기존 EXE는 별도로 종료해야 함.
주식 AT/MA/GMO/CLOSE, 코인 기본/MA 원장과 리서치를 분봉·점수대·실제/가상별로 조회.
MSERVER에 업로드되지 않은 옛 PC 리서치 데이터는 PC 조회기가 새로 생성하지 못함.
인증 실패 시 마지막 조회 자료를 '실시간 아님' 상태로 유지. 휴대폰 원본 불변.
