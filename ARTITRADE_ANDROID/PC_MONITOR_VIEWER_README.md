# ARTITRADE PC · 휴대폰 원장 조회 전용

사용법:
1. 기존 주식/코인 매매 EXE를 종료하고, Windows 시작프로그램에도 남아 있지 않은지 확인.
2. 휴대폰에서 Tailscale + MSERVER 실행, 통합 앱 원장 동기화 확인.
3. ARTITRADE_PC_MSERVER_READONLY_VIEWER_v1.0_20261113.exe 실행.
4. 휴대폰 Tailscale 주소(http://100.x.x.x:8765) 및 MSERVER 페어링 토큰 입력.
5. 최신 원장 조회. 이후 10초 간격 자동 재조회.
6. 통합 현황/리서치 분석/보유 종목/체결 이력/연결·원장 진단 탭 선택.

안전성:
- 서버로 전송하는 명령은 /v1/status, /v1/record/meta, /v1/record에 대한 GET뿐임.
- 가상매수·가상매도·실매수·실매도 엔진을 불러오지 않으며 주문을 제출하지 않음.
- 기존 EXE를 강제로 중지시키지는 않음. 구 EXE 종료 필수.
- 원장 데이터를 PC 로컬 SQLite로 저장하지 않음.
- 토큰 기억 선택 시 Windows DPAPI로 암호화 저장. 실패할 경우 평문 저장을 하지 않음.
- 연결 실패 시 화면의 직전 조회 결과는 표시할 수 있으므로, 시각을 반드시 확인.

리서치:
- 주식 AT/MA/GMO/CLOSE, 코인 기본/MA 각각 분리.
- 분봉 5m, 30m, 60m, day, 점수대 0~20, 21~40, 41~60, 61~80, 81~100.
- 실제 체결과 가상 진입을 별도로 목표달성률 계산 (HIT / (HIT + MISS)).
- 미진입 후보와 판정 미완료는 목표달성률 분모에서 제외.
- MSERVER에 자료가 없거나 오래된 경우 진단 탭에서 미전송으로 표시. 임의 복원하지 않음.
- 모바일 앱이 실제로 새로운 연구 결과를 게시해야 PC에서도 볼 수 있음. 업로드되지 않은 과거 PC 연구는 자동 생성 불가.
- MSERVER 접속 성공은 휴대폰 전략엔진의 시세 스트림 실시간 수신을 보증하지 않음. 원장 갱신은 폰 게시 주기와 PC 조회 주기를 따름.
