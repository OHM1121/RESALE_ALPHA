# ARTITRADE v0.7.52 종목별 종합분석

- PC MSERVER 및 Android 단일 통합 APK, 기존 거래·설정·계좌 원장 변경 없음.
- 사용자가 AI 분석 버튼을 눌렀을 때만 수행. 시장별/전략별/시간봉별 자료를 혼합하지 않음.
- 원본 SQLite·JSON 전체는 기존 검증 ZIP에 포함. 종목별 연결 결과만 연구 전용 `<market>/ai/AI_COMPREHENSIVE_V052.sqlite3`에 별도 저장.
- 분석은 로컬 통계·규칙 기반 요인 탐색이며 외부 거대언어모델의 원격 학습이나 자동매매 전략 변경이 아님.

## 데이터 정합성

- `LIVE`, `PAPER`, `SHADOW_UNFILLED`, `UNKNOWN_FILLED_LEDGER`를 구분.
- 매수 시점 이후의 최고가·저가·목표도달·손익 정보는 진입 원인 분석에 투입하지 않음.
- 입력 지표가 적은 경우 종목별 실제 성과표는 저장하되 인과관계나 전략 개선을 확정하지 않음.
- 같은 종목이라도 포지션 ID·진입시각이 일치하지 않으면 통합하지 않음.
- 20건 이하 단기 표본은 탐색만, 30건 이상은 기간순 학습/검증 분리로 방향 재현 가능성을 확인. 단, 통계가 곧 인과·주문 권고를 의미하지 않음.
- 원본 표본이 너무 많아 일부 자료만 분석한 경우 건수·누락 원인·제한을 화면과 저장소에 표시.
- 추후 데이터가 신규 수집되어 다시 분석하면 연구용 `trade_cases`, `source_inventory`, `analysis_runs`만 갱신됨.

## 검증 및 현재 한계

- 과거 OHLCV/지표가 최초 매매 당시 실제로 기록되지 않은 경우에는 시간이 맞는 기록만 진입 지표로 인정함.
- DB에 있는 모든 행이 자동으로 한 거래와 연결되는 것은 아님. ID/시각/출처가 불충분한 행은 `AVAILABLE_UNATTRIBUTED` 상태로 보존/표시함.
- 분석용 `roi`는 원본에 저장된 실현손익 근거가 있을 때만 포함하며, 미매수 가상 관측은 미실현/실현손익으로 분류하지 않음.
- 휴대전화 장시간 사용 및 실제 증권사 부분 체결은 테스트 기기에서 최종 확인 필요.
